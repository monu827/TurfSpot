# TurfSpot ⚽

TurfSpot is a full-stack web application designed to simplify sports turf booking and management. It helps users find and book suitable turfs online while enabling turf owners to manage their listings and reservations through a dedicated dashboard.

## Key Features
- Online turf discovery and booking
- User and turf owner interfaces
- Turf listing and management
- Booking management
- Secure authentication
- Online payment integration with Razorpay

## Tech Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Payments: Razorpay
- Media Storage: Cloudinary

## Purpose
The goal of TurfSpot is to make turf booking convenient for players and simplify daily operations for turf owners.
